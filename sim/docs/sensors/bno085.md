# BNO085 Model

The BNO085 is the primary inertial source. It uses dedicated SPI mode 3 at
3 MHz with SHTP framing and a modeled 94 ms startup delay.

| SH-2 report | ID | Rate | Encoding | Estimator use |
| --- | ---: | ---: | ---: | --- |
| Calibrated acceleration | `0x01` | 500 Hz | Q8 m/s2 | Latest sample held for gyro propagation |
| Uncalibrated gyro and bias | `0x07` | 400 Hz | Q9 rad/s | Propagation epoch and angular rate |
| Game rotation vector | `0x08` | 100 Hz | Q14 quaternion | Diagnostic only |

Every packet has the four-byte SHTP header, little-endian packet length,
continuation flag, channel number, and wrapping channel sequence. Arrival is
the modeled `H_INTN` ready time plus the complete SPI transfer, with bus
serialization when reports overlap.

The physical model applies mounting rotation, scale error, misalignment, bias,
bias random walk, optional first-order filtering, quantization, and saturation.
Acceleration is limited to plus or minus 8 g. Gyro is limited to plus or minus
2000 degrees per second. Undocumented noise and vehicle-specific values default
to zero and remain bench-calibration inputs.

`Bno085Model.startup_trace()` emits deterministic advertisement and Set Feature
traffic used by the golden protocol test. Fault tests cover loss, duplicate
channel sequence, truncation, continuation parsing, and reset behavior.

References: [BNO08X datasheet](https://www.ceva-ip.com/wp-content/uploads/BNO080_085-Datasheet.pdf),
[SH-2 reference](https://www.ceva-ip.com/wp-content/uploads/SH-2-Reference-Manual.pdf),
and [SHTP specification](https://www.ceva-ip.com/wp-content/uploads/Sensor-Hub-Transport-Protocol.pdf).
