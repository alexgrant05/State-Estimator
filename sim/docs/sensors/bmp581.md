# BMP581 Model

## Role

The BMP581 supplies static pressure and temperature. The estimator converts
pressure to launch-relative altitude for coast-phase vertical aiding.

## Sampling and timing

- Default output rate: 50 Hz
- Measurement timestamp: scheduled data-ready epoch
- Acquisition size used for scheduling: 72 bits
- Final arrival: assigned by shared SPI arbitration with ADXL priority
- Default SPI clock: 5 MHz

Truth and atmosphere values are interpolated to each measurement epoch.

## Pressure and temperature model

Pressure starts from the standard atmosphere evaluated at truth MSL altitude.
The model adds:

- a Gaussian-shaped equivalent-altitude disturbance around transonic flight
- configured pressure bias and bias random walk
- Gaussian pressure noise
- optional deterministic fault spikes

Temperature starts from ambient atmosphere temperature and adds Gaussian noise.

The transonic altitude disturbance is:

```text
error_m = peak_m * exp(-0.5 * ((mach - center) / sigma)^2)
```

The atmosphere is evaluated at `altitude_msl_m + error_m`.

## Raw scaling and acquisition

| Field | Encoding |
| --- | --- |
| Temperature | Signed 24-bit two's complement, `2^16` LSB/deg C |
| Pressure | Unsigned 24-bit, `2^6` LSB/Pa, clipped to 30,000 through 125,000 Pa |
| Interrupt status | One byte, default `0x01` |

The logical payload contains three little-endian temperature bytes, three
little-endian pressure bytes, and status, for 7 bytes. The 9-byte binary replay
adds read command `0x9D` before data and status command `0xA7` before status.

Pressure clipping sets `SATURATED`.

## Fault injection

`BmpFaultSchedule` supports:

- invalid diagnostic status
- packet loss
- per-sample pressure spikes in pascals

Invalid status clears `VALID` and sets `DIAGNOSTIC_ERROR`.

## Estimator handling

Pad pressure samples are averaged into the reference pressure. Updates are
suppressed during boost and within the configured transonic Mach proxy range.
Outside those phases, pressure is converted with the barometric formula and
referenced to pad altitude. A one-dimensional NIS gate protects the vertical
position update. Measurement noise is mapped from pressure to altitude using a
local pressure derivative and is floored at 0.05 m standard deviation.

## Current limitation

Configured oversampling values are validated, and the IIR coefficient is
recorded. Neither currently changes conversion delay or noise bandwidth.
Pressure-port dynamics, thermal lag, and installed airflow behavior require
hardware test data.
